TaskFlow – Task Management Web Application

1. Introduction

TaskFlow is a web-based task management application that helps users organize and manage their daily tasks easily. Users can create an account, log in and add tasks through a simple interface.

2. Objectives

- To manage daily tasks easily.
- To provide user registration and login.
- To organize tasks in one place.
- To provide a user-friendly interface.
- To store application data in a database.

3. Features

- User Signup
- User Login
- User Authentication
- Add Tasks
- Database Connectivity

4. Technologies Used

Frontend:

- HTML
- CSS
- JavaScript

Backend:

- Node.js
- Express.js

Database:

- MongoDB Atlas

5. Project Structure

- "backend/" – Backend files and server-side logic.
- "frontend/" – Website interface and frontend files.

6. Working of the Project

1. User opens the TaskFlow application.
2. New users can register.
3. Existing users can log in.
4. The frontend communicates with the backend.
5. The backend handles user authentication and task requests.
6. MongoDB Atlas is used for data storage.

8. Installation and Setup

Step 1: Clone Repository

git clone https://github.com/tkritika243/TaskFlow-Project.git

Step 2: Open Backend Folder

cd backend

Step 3: Install Dependencies

npm install

Step 4: Configure Environment Variables

Create a ".env" file with the required database and authentication settings. Keep secret values private.

Step 5: Start Backend

node server.js

Step 6: Open Frontend

Open "index.html" in your browser.
